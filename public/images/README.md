# Photo slots

Drop your photos in this folder using these exact file names (JPG). Until a file
exists, the site shows a random placeholder in that slot.

| File            | Where it appears                          | Suggested size |
| --------------- | ----------------------------------------- | -------------- |
| `hero.jpg`      | Hero fallback when 3D cannot run          | 1920 x 1200    |
| `view-far.jpg`  | View section, large back photo            | 1600 x 1100    |
| `view-mid.jpg`  | View section, tall photo on the right     | 900 x 1200     |
| `view-near.jpg` | View section, small square front photo    | 900 x 900      |
| `room-1.jpg`    | Lotus Room (large card)                   | 1400 x 1100    |
| `room-2.jpg`    | Pine Room                                 | 1000 x 600     |
| `room-3.jpg`    | Terrace Room                              | 1000 x 600     |
| `meals.jpg`     | The stay, home-cooked meals tile          | 1400 x 900     |
| `walks.jpg`     | The stay, walks tile                      | 1600 x 700     |
| `day.jpg`       | A day at Padma, pinned photo              | 1100 x 800     |

Keep each file under about 400 KB so the page stays fast.
