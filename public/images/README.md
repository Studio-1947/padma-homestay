# Photo slots

Drop your photos in this folder using these exact file names (JPG unless noted). Until a
file exists, the site shows a stand-in photo in that slot.

| File            | Where it appears                          | Suggested size |
| --------------- | ----------------------------------------- | -------------- |
| `dhotrey-layer-back.webp`, `-middle.webp`, `-front.webp` | Hero parallax layers, cut from `dhotrey.jpeg` by depth | 2400 wide |
| `sunset.webp`   | "The ridge changes every hour", all three photos | 1600 wide or more |
| `room-1.jpg`    | Lotus Room (large card)                   | 1400 x 1100    |
| `room-2.jpg`    | Pine Room                                 | 1000 x 600     |
| `room-3.jpg`    | Terrace Room                              | 1000 x 600     |
| `meals.jpg`     | The stay, home-cooked meals tile          | 1400 x 900     |
| `walks.jpg`     | The stay, walks tile                      | 1600 x 700     |
| `day.jpg`       | A day at Padma, pinned photo              | 1100 x 800     |
| `gallery-1.jpg` | Gallery: the house from the garden path   | 1200 x 1500    |
| `gallery-2.jpg` | Gallery: morning light on the range       | 1600 x 1067    |
| `gallery-3.jpg` | Gallery: momos in the kitchen             | 1200 x 1200    |
| `gallery-4.jpg` | Gallery: rhododendrons on the trail       | 1200 x 1600    |
| `gallery-5.jpg` | Gallery: the terrace at dusk              | 1600 x 1067    |
| `gallery-6.jpg` | Gallery: a guest room made up             | 1200 x 1500    |
| `gallery-7.jpg` | Gallery: prayer flags above the village   | 1600 x 1067    |
| `nearby-tonglu.jpg`, `nearby-singalila.jpg`, `nearby-sandakphu.jpg`, `nearby-tumling.jpg`, `nearby-maneybhanjang.jpg` | Around Dhotrey cards | 900 x 1100 |

Gallery photos can be any shape: change `width` and `height` for that photo in
`src/content/site.ts` to match the real file, and the wall rearranges itself.

Keep each file under about 400 KB so the page stays fast.
